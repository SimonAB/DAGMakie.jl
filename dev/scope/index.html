Scope & design boundaries

DAGMakie.jl is a visualisation-only package for causal diagrams on Makie and GraphMakie. It draws what the user or an upstream identification package already specified; it does not compute identification certificates, fit models, or run simulations. See also BOUNDARIES.md and the shared DESIGN_PRINCIPLES.md.

Ownership across the CDCS stack

PackageRoleBoundary with DAGMakie
DAGMakie.jl (this package)Causal DAG / digraph / mixed-graph figures, layered & temporal layouts, themes, edge routing, display conventionsCore depends only on Graphs, Makie, GraphMakie, NetworkLayout, and Reexport
CausalDynamics.jlStructural graphs, identify certificates, TemporalUnrolling, SCM/CDM simulationSupplies IdentificationResult and TemporalUnrolling via its CausalDynamicsDAGMakieExt weakdep
CausalInference.jld-separation and adjustment-set searchOptional weakdep (DAGMakieCausalInferenceExt) for highlighting when loaded
CausalTargeted.jl / CausalMediation.jlLMTP, Super Learner, Bayesian g-computation, and mediation EIF estimationOut of scope here; stress notebooks call dagplot for figures only

What is in scope

  • Layered & SCC-aware layouts: deterministic layered layout for acyclic graphs, SCC-aware layout with curved feedback overlays for cyclic graphs, and NetworkLayout fallbacks.
  • Temporal & skeleton layouts: dagplot_time_indexed, dagplot_temporal, and dagplot_skeleton. Temporal glyphs read declared value_representation (:interval_summary only uses rounded rectangles); support and referent identity are never inferred from shape.
  • Causal conventions & visual grammar: observed vs latent styling, bidirected confounding (MixedGraph), dagitty-style color_by role colouring, display-only do(·) surgery (do_surgery, dagplot_do), interaction IDAGs, and DiD SWIGs.

What is out of scope

  • Computing adjustment sets, d-separation, or identify in core (belongs in CausalInference.jl / CausalDynamics.jl).
  • Statistical estimation, Super Learner, LMTP, or mediation EIF.
  • Cohort data, registries, or hierarchical model fitting.
  • Inventing ontology from glyphs or layout (:occasion / :enduring belong in book prose and CausalDynamics.ReferentSpec; node count follows temporal_support + graph_kind).
  • Hard dependency on CausalDynamics, CausalInference, or Graphviz (dot).
  • Interactive WebGL graph exploration for massive graphs (target scale is notebook- and publication-scale causal diagrams, roughly 5–200 labelled nodes).

Validation checks

  • Geometry & API regressions: test/test_layout.jl, test/test_temporal_layout.jl, test/test_auto_align.jl, test/test_highlighting.jl, and test/test_interventions.jl.
  • Optional extension tests: test/test_smart.jl and test/test_causaldynamics_ext.jl.
  • Package QA: Aqua.jl ambiguity and piracy checks in test/test_aqua.jl.
  • Optional timing budgets: set DAGMAKIE_PERF=1 when running the test suite (test/test_perf.jl), or run the manual timing gallery via julia --project=. test/benchmark_layouts.jl.
